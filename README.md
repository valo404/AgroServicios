
# AgroServicios

Directorio de servicios y maquinaria rural para la ciudad de Paysandú.
Con la aspiración de crecer y llegar a todo el Uruguay para ofrecer un servcio que facilite la obtención de información y comunicación al sector rural, brindando más servicios y favoreciendo tanto a las empresas como a las personas que harán uso de la misma.
